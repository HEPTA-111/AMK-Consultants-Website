# AMK Consultants Website
Static HTML, CSS and JavaScript. No build step.

## Deploy (GitHub Pages)
Settings > Pages > Deploy from branch `main` / root.

## Before launch
1. Contact form: create a free Web3Forms key and set it in `data-key` on `<form id="inquiry">` in `index.html`.
2. Domain: when `amkconsultants.co.ke` is live, update the URLs in `sitemap.xml` and `robots.txt`.
3. Legal: have the Privacy Notice (`privacy.html`) reviewed.

## Replacing photos (overwrite, same file name)
- Hero: `assets/images/hero/nairobi-skyline.jpg` (2000px wide) and `-1200.jpg`
- Sector tiles: `assets/images/sectors/<name>.jpg` (900x600) and `<name>-600.jpg` (600x400)
- Spotlights: `assets/images/energy/*.jpg` (800x800)
- Statement band: `assets/images/band/aviation-sunset.jpg` (2000px) and `-1200.jpg`
- Social preview: `assets/images/social/og-image.jpg` (1200x630)
