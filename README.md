# AMK Consultants Website
Static HTML, CSS and JS. Deploy: GitHub > Settings > Pages > Deploy from branch `main` / root.
Images live in `assets/images/` (hero, sectors, social, logo). Replace a photo by overwriting the same file name; sector tiles are 720x960 (plus a 480x640 `-480.jpg`), hero is 2000px wide (plus `-1200.jpg`).
Form: get a free Web3Forms access key and set it in `data-key` on the form in `index.html`.
